# HOUSIE

Before doing anything install nodejs(any recent video works)
FOR HOSTS::
1) Download all files
2) Extract all files
3) Go to file, click on the address bar, and type cmd+enter
4) In command prompt, type npm install
5) Then type ipconfig
6) Look for IP4 and copy that address for sending it with players(example-192.162.13.91)
7) Type npm start
8) You will get some output like localhost:3000
9) Go there and create your game or join game

FOR PLAYERS::
1) Once the host shares the IP4 address type that with :3000(example 192.162.13.91:3000)
2) Then join the game enter code and name


ENJOY YOUR GAME!
